**AURA.3D** is an ultra-immersive spatial hardware shopping website that redefines online commerce by blending WebGL 3D graphics, procedural shader materials, raytraced lighting, and high-fashion cyberpunk design.

---

## 🌟 Key Features

### 1. 🎮 Interactive 3D WebGL Showroom
- **3D Exploded Component View**: Dismantle hardware into floating sub-assemblies (Sapphire glass, 165Hz OLED display, Li-Ion battery cells, triple prism optics, and Grade 5 titanium chassis) with in-space holographic tags.
- **Dynamic Material Swatches**: Instant finish customization (Hyper Cyan, Electric Violet, Liquid Titanium Chrome, Solar Amber, Obsidian Void).
- **Shader Pipeline**: Switch between photorealistic raytraced PBR and holographic neon wireframe shaders.
- **Atmospheric Lighting Presets**: Cyberpunk Raytrace, Electric Aurora, Solar Sunset, and Pure Titanium.
- **360° Free Orbit & Zoom**: Full touch and mouse spatial drag physics.

### 2. 🔍 Dedicated 3D Product Inspector Lightbox
- Category-aware procedural 3D models for Smartphones, Laptops, Audio Gadgets, Luxury Apparel, and Architectural Furniture.
- In-depth specifications, certified warranty telemetry, stock status, and quantity pickers.
- Direct "Instant Checkout" or "Add to Vault Bag".

### 3. 🛍️ Full E-Commerce Storefront
- **Authentic Catalog**: 71 products, 7 categories, and 6 brands extracted from MySQL database.
- **Flash Drop Banner**: Segmented holographic neon countdown timer with real-time ticking.
- **Filters & Search**: Instant keyword search, brand filter chips, and interactive budget range slider.
- **Vault Bag**: Slide-out cart with working VIP promo codes (`NEO2026` for 20% off, `VIP50` for 50% off).
- **3-Step Cryptographic Checkout**: Air courier destination, payment selection (Card, Apple Pay, Cash on Delivery), and celebratory confetti shower with printable invoice receipt.
- **Wishlist Vault**: Persistent bookmarks stored in `localStorage`.
- **Spatial Audio Synthesizer**: Zero-latency Web Audio API tactile acoustic feedback.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/akshaysharma2005/online-shopping-system-3d.git
cd online-shopping-system-3d

# Install dependencies
npm install

# Start Vite 3D dev server
npm run dev
```

Open your browser to: `http://localhost:5174/`

---

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 7
- **3D Engine**: Three.js 0.182 + `@react-three/fiber` + `@react-three/drei`
- **Animation**: GSAP + `@gsap/react` + WebGL Render Loop
- **Audio**: Web Audio API Sound Synthesizer
- **Styling**: SCSS Glassmorphism + Avant-garde Editorial Typography (`Syne`, `Outfit`, `JetBrains Mono`)
- **FX**: `canvas-confetti` + `lucide-react`
